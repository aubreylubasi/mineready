# MineReady web app

MineReady keeps mine contractors' company and worker documents (PACRA, ZRA tax clearance, NAPSA, medicals, site inductions, training certificates) in one place, warns before anything expires, shows which workers are cleared for which mine, and builds the contractor file as a PDF.

Live at **https://mineready.aubreylubasi.dev**

- Works in any browser on a computer or phone. On a phone, use Add to Home Screen to install it.
- Records stay in the browser on that device. There is no server and no account.
- Works offline once opened.
- Try it with the built-in sample data (a fictional company and workers).

Version 1.0.1. Privacy policy: `privacy.html`. Terms: `terms.html`.
